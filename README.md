# 경영개선 포털 사용법

업무 혁신(PI)과 윤리경영 안내를 한곳에 모은 내부 안내 포털입니다. 별도 설치나 서버 없이 `index.html` 하나로 동작합니다.

## 1. 열기

1. 이 폴더의 `index.html`을 더블클릭해 브라우저(Chrome·Edge 권장)로 엽니다.
2. 인터넷 연결이 없어도 열립니다.
3. 입력한 내용은 이 화면에서만 계산되며 저장되거나 외부로 전송되지 않습니다.

## 2. 폴더 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 포털 본체 (현재 버전) |
| `files/pi-promotion-guide.pdf` | 업무혁신 PI 추진 가이드 |
| `files/ethics-code-of-conduct.pdf` | 윤리강령·행동규범 |
| `이전버전/portal-v2-uri-buseo.html` | 디자인 시스템 적용 시점의 `index.html` 사본 |
| `README.md` | 이 문서 |

## 3. 화면별 사용법

상단 메뉴를 누르면 해당 위치로 이동하고, 지금 보고 있는 영역의 메뉴가 강조됩니다.
- 화면이 좁으면(모바일·태블릿) 메뉴가 햄버거(≡) 버튼으로 접힙니다. 버튼을 누르면 펼쳐지고(✕로 바뀜), 메뉴 항목을 누르면 이동과 함께 자동으로 닫힙니다.
- 접힌 상태에서도 상단에 현재 영역 이름이 함께 표시됩니다.
- 메뉴 바깥을 누르거나 Esc 키를 눌러도 닫힙니다.

| 메뉴 | 할 수 있는 일 |
|---|---|
| 홈 | 포털 소개. 「우리 팀 자가점검 시작」「개선 효과 계산하기」 버튼으로 바로 이동 |
| 역할 | 경영개선 조직의 4가지 역할(경영 효율화, PI, 진단/감사, 체질 개선) 확인 |
| PI 단계 | PI 추진 4단계(As-Is 분석 → 개선안 도출 → 실행 → 정착) 확인 |
| 혁신 사례 | 개선 전·후 비교 사례 확인 (현재 **예시 데이터**) |
| 자가점검 | 우리 팀에 해당하는 낭비 항목을 체크해 개선 우선순위 확인 |
| 효과 계산기 | 개선 전·후 소요시간과 월 처리 건수로 절감 효과 계산 |
| 윤리경영 | 윤리·내부통제 안내 확인, 「공식 제보 채널 안내 보기」로 제보 방법 확인 |
| FAQ | 키워드 검색 또는 질문을 눌러 답변 확인 |
| 자료실 | 윤리강령·개선 제안 양식(샘플) 내려받기, `files/` 폴더의 공식 문서(PDF) 목록 확인과 다운로드 |

### 자가점검
- 낭비 항목 8개(중복 업무, 대기 시간, 수작업, 재작업, 불필요한 보고·회의, 정보 단절, 업무 기준 불명확, 과도한 문서화) 중 해당하는 것을 모두 체크합니다.
- 오른쪽 결과 카드에 우선순위가 표시됩니다: 0~2개 **낮음**, 3~5개 **보통**, 6~8개 **높음**. 체크한 항목별 개선 방향도 함께 나옵니다.
- 「선택 초기화」로 처음부터 다시 할 수 있습니다.

### 효과 계산기
1. 개선 전 소요시간(건당, 분), 개선 후 소요시간(건당, 분), 월 처리 건수(건)를 입력합니다.
2. 절감률, 월 절감 시간, 연 환산 절감 시간이 자동으로 계산됩니다.
3. 계산식: 월 절감 시간 = (개선 전 − 개선 후) × 월 처리 건수 ÷ 60 / 절감률 = (개선 전 − 개선 후) ÷ 개선 전 / 연 환산 = 월 절감 시간 × 12
4. 「입력 초기화」로 값을 지웁니다.

### FAQ
- 검색창에 키워드(예: 제보, PI, 계산, 승인)를 입력하면 해당 질문만 남습니다.
- 검색창 아래의 카테고리 버튼(전체, PI 개념·대상, PI 추진 절차, PI 효과 측정, 윤리 – 금품·접대 등)을 누르면 그 분류의 질문만 보입니다. 키워드 검색과 함께 쓰면 선택한 분류 안에서만 검색합니다. 「전체」를 누르면 다시 모두 보입니다.
- 카테고리 버튼은 FAQ 목록의 분류 제목에서 자동으로 만들어지므로, 질문이나 분류를 추가해도 버튼은 따로 고치지 않아도 됩니다.
- 각 답변 끝의 「근거」에 출처 문서와 쪽수가 적혀 있습니다.

### 자료실 파일 목록
- 「공식 문서 (PDF)」 목록에 파일명·설명·용량이 표시되고, 「다운로드」를 누르면 새 창 없이 바로 저장됩니다. 저장되는 파일명은 한글 이름입니다.
- 파일을 추가하려면 `files/` 폴더에 넣고, `index.html`의 `<ul class="doc-list">` 안에서 항목(`<li class="card doc">`) 하나를 복사해 `href`(영문 경로)·`download`(저장될 한글 이름)·설명·용량을 고쳐 주세요.

## 4. 게시 전에 꼭 할 일

`index.html`을 텍스트 편집기로 열면 아래쪽 `<script>` 맨 위에 `CONFIG`가 있습니다.

1. **공식 제보 채널**: `CONFIG.report`의 전화번호·이메일·운영시간·안내 문구·주소(url)를 실제 값으로 바꿉니다. 바꾸기 전에는 `[…입력]` 자리표시자가 그대로 보입니다.
2. **자료실 파일**: `CONFIG.files`의 `url`에 공식 파일 경로(예: `files/ethics-code-of-conduct.pdf`)를 넣으면 샘플 초안 대신 해당 파일이 내려받아집니다. 비워 두면 샘플 초안(.txt)이 생성됩니다. 파일을 연결할 때는 자료실 카드의 「TXT」 표시와 「샘플 초안」 안내 문구도 함께 고치세요.
3. **혁신 사례**: 현재 사례는 가상 데이터입니다. 실제 사례·수치로 교체하거나 안내 문구를 삭제하세요.

## 5. 참고

- 내용 수정은 `index.html`의 텍스트를 직접 고치면 됩니다. 색·글꼴·여백은 파일 맨 위 `<style>`의 `:root` 값(우리 부서 포털 디자인 시스템 토큰)을 바꾸면 한꺼번에 바뀝니다.
- 수정하기 전에 `index.html`을 복사해 두면 안전합니다.
